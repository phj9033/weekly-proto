# 꼬리 · 2026-09-17 (이번 주 프로토타입 01)

붙잡은 적이 내 뒤에 마디로 붙어 옆으로 쏘고 대신 맞는다. 몸집이 늘어 벽 사이를 못 지난다. 몇 마디까지 키울지가 매 순간의 판이다.
기획 도구가 5개 중 1등으로 뽑은 기획을 **그대로** 만들었다. 이번 회 제약은 갤러그의 「붙잡는 빔」(부수지 않고 붙잡는다).

## 조작
- 화살표 / WASD 이동 · 방향 = 마지막 이동 방향
- **Z 누르고 있기** = 붙잡기. 앞 부채꼴 안 가장 가까운 적에 게이지(빠른 적 0.8초 · 큰 적 1.5초). 누르는 동안 이동 절반. 손을 떼면 게이지 0
- **X** = 부수기. 머리 앞 1발 + 마디 수만큼 옆으로 1발씩
- **C** = 끝 마디 떼기(중립 표류체로 되돌린다 · 다시 붙잡거나 부술 수 있다)
- ESC 멈춤 · Enter 같은 시드 다시 · R 다음 시드(6개) · L 판 로그 JSON 저장

## 규칙
- 적탄·적 몸이 **마디**에 닿으면 그 마디만 잃는다(큰 적 마디는 2발). **머리**에 닿으면 끝
- 벽에 걸린 마디가 앞과 3칸 넘게 벌어진 채 0.5초 버티면 그 마디부터 뒤가 떨어져 중립이 된다
- 30초마다 등장이 빨라지고 60초부터 큰 적. 90초 생존이면 끝. 점수 = 처치 + 끝날 때 꼬리 길이 × 5
